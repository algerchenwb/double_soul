# 细纲（第 4 章）

### 第 4 章：雨停之前
- 核心事件：审讯暂歇，崔承礼在狱中养伤、整理封泥与旧账，和陈砚第一次平静讨论彼此底线；章末得知周六家属将被转押。
- 字数目标：2100 字
- 字数口径：visible_chars_v1
- 单元ID/位置：第一卷军粮案开端／第 4 拍，关系沉淀与代价确认
- 目标情绪：高压后的疲惫 → 对彼此的试探与理解 → 新的缓慢不安
- 主角目标/关键选择：保存封泥、厘清柳湾线索；选择暂不冒险出狱，而是先确认周六家属的去向。
- 章首钩子：余波钩子 — 门重新锁上，崔承礼才发现掌心被封泥磨破
- 爽点：无显性爽点；以一顿热粥和一次短暂安静兑现喘息，但留下转押压力
- 本章禁止提前释放：不去柳湾；不让周六家属获救；不解释双魂来源；不让崔承礼与陈砚彻底和解。

#### 内容概括（五段式）
- 起因：县吏离开后，崔承礼发现封泥和伤势都需要处理。
- 发展：两人整理有限信息，陈砚问起崔家旧账，崔承礼讲出父亲曾如何教他辨封与保结。
- 转折：狱卒送来一碗冷粥，透露周六家属将在天亮前被转往别处；崔承礼意识到“等出去”也可能来不及。
- 高潮：两人争执是否立即冒险，崔承礼最终选择把封泥藏好，并记下周六说过的柳湾第三块石阶。
- 结尾：雨声变小，门外传来换班与搬动木枷的声音，狱卒说“明早第一批押走的，就是后院那几口人”。

#### 情节安排（多线）
- 主线推进：L01 从取得物证推进到确认调查时间窗口正在缩短。
- 辅线推进：L02 从共同取证推进到形成最低限度的共处规则。
- 事件线 / 任务线：狱中整理证据、确认周六家属转押安排。
- 感情线 / 关系线：无显性；两魂从争辩转为约定“重要决定必须互相知情”。
- 逻辑线：审讯暂歇 → 整理物证 → 交换旧账与底线 → 得知家属将转押 → 约定下一步。

#### 人物关系和出场顺序
- 出场顺序：崔承礼、陈砚、狱卒。
- 人物关系变化：两魂建立最低限度的共同决策规则；狱卒从旁观者变成提供时间信息的灰色帮手。
- 视角/信息差：主角知道封泥和柳湾线索；读者知道时间紧迫；狱卒知道转押命令但不愿承担更多风险。
