# 细纲（第 2 章）

### 第 2 章：名册上的替罪羊
- 核心事件：县吏逼崔承礼承认誊账有误，崔承礼借查看名册反守为攻，发现外姓船户周六被列为主要责任人。
- 字数目标：2200 字
- 字数口径：visible_chars_v1
- 单元ID/位置：第一卷军粮案开端／第 2 拍，承接审讯并锁定替罪羊
- 目标情绪：被动受审的窒息 → 抓住一线反问权的紧张 → 发现弱者将被推出去的愤怒与责任感
- 主角目标/关键选择：保住查看原始名册的机会；选择不立刻洗脱崔家，而是先阻止周六被押走。
- 章首钩子：反问落空 — 县吏把仓址问题改成认罪问题
- 爽点：无显性爽点；崔承礼第一次用名分和陈砚的算术逼县吏让出一寸证据空间
- 本章禁止提前释放：不揭示崔父全貌；不确认幕后主使；不让县吏承认侵吞；不让崔承礼立即获释。

#### 内容概括（五段式）
- 起因：县吏回避仓址，要求崔承礼承认自己誊账失误。
- 发展：崔承礼提出查看押运名册，以“若是我的错，便能指出哪一船少粮”为由争取文书；陈砚发现名册将周六列为责任人。
- 转折：狱卒透露周六已被关在杂役房，家属也被扣下；崔承礼意识到案件正把损失转嫁给无保结的船户。
- 高潮：崔承礼拒绝在供词上落押，反问名册为何没有仓吏复核印；县吏第一次真正动怒。
- 结尾：县吏命人把周六带来“对质”，门外传来拖链声。

#### 情节安排（多线）
- 主线推进：L01 从军粮案疑点推进到替罪羊与原始名册。
- 辅线推进：L02 双魂合作从试探推进到共同承担保人的选择。
- 事件线 / 任务线：审讯被卡住，证据获取窗口打开，但证人安全恶化。
- 感情线 / 关系线：无显性；崔承礼开始承认陈砚的判断有用，陈砚第一次接受“不能只算账”的责任。
- 逻辑线：县吏逼供 → 主角索取名册 → 发现周六被列责 → 拒绝落押 → 周六被押来对质。

#### 人物关系和出场顺序
- 出场顺序：县吏、崔承礼、陈砚、狱卒、船户周六（章尾只露声音与脚步）。
- 人物关系变化：崔承礼与陈砚由临时互助变为共同决策；县吏将崔承礼视为不肯就范的麻烦；周六成为待保护证人。
- 视角/信息差：县吏知道周六已被控制；主角只知道名册责任栏；读者不知道粮食真正去向。
