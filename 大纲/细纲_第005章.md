- 核心事件：崔承礼利用狱卒留下的换班铜牌传话，却发现周六家属已提前转押；他必须在追回封泥和追问家属去向之间做选择。

- 字数口径：visible_chars_v1

- 目标情绪：准备行动的克制 → 计划被提前打乱的失控 → 牺牲证物保护一个具体人的沉重
- 主角目标/关键选择：让至少一名周六家属留下可追查的姓名和去向；选择将封泥交给狱卒带出，换取一条不可靠的传话机会。
- 章首钩子：倒计时 — 后院木枷声提前响起
- 爽点：非传统爽点；崔承礼第一次主动设计局面，让县衙无法把七个人一起抹掉
- 本章禁止提前释放：不让家属全部获救；不验证柳湾；不让狱卒成为可靠盟友；不揭示县吏真正上级。

#### 内容概括（五段式）
- 起因：后院提前响起木枷声，转押比狱卒说的时间更早。
- 发展：崔承礼用铜牌制造短暂混乱，试图向后院传话，却只能见到周六的长女阿芹。
- 转折：阿芹拒绝带口信，要求崔承礼先说出她父亲的真名与船号；陈砚意识到他们一直把家属当成被救对象，没有当成有选择的人。
- 高潮：崔承礼交出封泥给狱卒，请其带出并换取在转押簿上留下七人姓名；狱卒只答应写下一个名字。
- 结尾：崔承礼选择留下阿芹的名字，其他六人的去向暂时消失在转押簿的空白里。

#### 情节安排（多线）
- 主线推进：L01 从获得证物推进到转押簿与失踪家属线。
- 辅线推进：L02 从共同规则推进到共同承担“只能救一个”的代价。
- 事件线 / 任务线：传话失败、证物交换、转押名册留下一个可追查姓名。
- 感情线 / 关系线：无显性；崔承礼与陈砚第一次因救谁发生真正分歧，最终共同承担选择。
- 逻辑线：转押提前 → 制造混乱 → 接触阿芹 → 交证物换名额 → 七人变一名。

#### 人物关系和出场顺序
- 出场顺序：狱卒、崔承礼、陈砚、阿芹、县吏。
- 人物关系变化：阿芹不再只是被救家属；狱卒与主角形成一次有代价的临时交易；双魂共同背负选择。
- 视角/信息差：阿芹知道家属内部谁最可能被拆散；县吏知道转押簿可被抹除；主角只保住一个姓名。
