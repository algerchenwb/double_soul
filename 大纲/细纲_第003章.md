# 细纲（第 3 章）

### 第 3 章：周六的手印
- 核心事件：周六被押来对质，在恐惧中说出第七船曾被临时换封的细节；崔承礼从旧账中认出父亲曾批准过向弱户摊损的做法。
- 字数目标：2300 字
- 字数口径：visible_chars_v1
- 单元ID/位置：第一卷军粮案开端／第 3 拍，证人对质与责任反转
- 目标情绪：证人被迫沉默 → 找到可核验证词的紧张 → 主角发现自家也有责任的刺痛
- 主角目标/关键选择：让周六安全说完一条可核验事实；选择不替父亲辩护，先承认崔家旧账存在。
- 章首钩子：对质登场 — 周六被锁链推入狱房，第一句话不是喊冤而是求县吏别碰家人
- 爽点：无显性爽点；崔承礼用自己承担的风险换得周六说出换封地点
- 本章禁止提前释放：不揭示粮食最终去向；不确认县吏幕后身份；不让周六完全信任崔承礼；不彻底洗清或定罪崔父。

#### 内容概括（五段式）
- 起因：周六被押来，县吏要求他复述“第七船少粮”的口供。
- 发展：周六因家属被扣而反复改口；陈砚发现他真正记住的是封泥和换船时间。
- 转折：崔承礼拿出自己愿承担军前移交的代价，周六说出第七船在柳湾被迫换封。
- 高潮：崔承礼看到名册附页上的旧摊损批注，确认批注有父亲的旧签，承认崔家不能只做受害者。
- 结尾：县吏收走附页，命人把周六带回去；崔承礼在地上摸到一小块脱落的封泥，陈砚说这才是他们第一件能带出去的证据。

#### 情节安排（多线）
- 主线推进：L01 从替罪羊确认推进到可核验的换封地点。
- 辅线推进：L02 从共同保护证人推进到共同承担崔家旧责。
- 事件线 / 任务线：对质过程中证词被权力操控，取得封泥实物但证人仍未安全。
- 感情线 / 关系线：无显性；崔承礼与陈砚首次因“是否承认家族旧责”形成短暂分歧后重新合作。
- 逻辑线：周六被逼供 → 主角换取信任 → 说出柳湾换封 → 旧账批注牵出崔父 → 封泥成为新证据。

#### 人物关系和出场顺序
- 出场顺序：周六、县吏、狱卒、崔承礼、陈砚。
- 人物关系变化：周六从被控制的证人变成有限合作证人；崔承礼与父亲之间的清白假设破裂；陈砚开始要求共同承担责任。
- 视角/信息差：周六知道柳湾换封但不知道幕后；县吏知道附页危险；读者第一次看到崔父旧签的存在。
